# David's Default Tech Stack

These are David's default tools and frameworks.
Use them for new work unless a project clearly dictates otherwise.

## Languages

- TypeScript - default for web, tooling, and most application code.
- Rust - for performance-critical and systems work.
- Elixir - for concurrent and fault-tolerant applications built on OTP.

## Frontend

- React with Vite.
- TanStack (Router, Query, and friends) for routing and data fetching.

## Tooling

- bun as the runtime and package manager for JS/TS projects.

## Testing

- Vitest for unit and integration tests.
- Playwright for end-to-end browser testing.

## Data

- PostgreSQL as the default database.
